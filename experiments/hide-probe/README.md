# 🧪 SavePoint 하이드 실험 (Hide Probe 0.1.1)

> **실험 결과 (0.1.1, 실제 실리태번):** 고른 메시지는 AI 요청에서 정확히 빠졌지만, 채팅을 직접 읽어 장면 상태를 넣는 다른 확장이 뺀 내용을 다시 넣었어요. 같은 메시지를 `/hide`로 숨기면 그 확장도 건너뛰었어요. 그래서 하이드는 지금처럼 숨김 표시(👻)를 쓰기로 했어요. 자세한 건 `docs/PLAN-v0.7.md` "그 뒤" 2번. 이 폴더는 기록으로 남겨 둬요.

**SavePoint 본체가 아니에요.** 따로 설치하는 작은 시험용 확장이에요. SavePoint와 함께 켜 둬도 서로 건드리지 않아요.

알아보려는 것: 메시지를 **AI에 보내는 요청에서만** 빼고, 채팅 파일은 그대로 둘 수 있는가.
- 고른 메시지는 실리태번의 `generate_interceptor`에서 요청 목록으로부터 빠져요.
- 이 확장은 채팅 파일을 쓰지 않아요. 고른 메시지 목록은 실리태번 설정(`settings.json`)에 저장돼요.
- 메시지의 숨김 표시(`is_system`)도 바꾸지 않아요. 화면에는 주황 점선과 `🧪 AI 요청에서 뺌(실험)` 표시만 나와요.
- 다른 확장보다 **먼저** 실행돼요(`loading_order: 1`). 그래서 Vector Storage 같은 확장이 숨긴 원문을 옮겨 다시 넣을 수 없어요.

## 설치 (PC)
1. 깃허브 레포 첫 화면에서 `Code` → `Download ZIP`으로 받아서 압축을 풀어요.
2. 안에 있는 `experiments/hide-probe` 폴더를 복사해요.
3. 실리태번 폴더의 `data/default-user/extensions/` 안에 붙여 넣고, 폴더 이름을 `SavePoint-HideProbe`로 바꿔요.
4. 실리태번 화면을 새로고침해요. 확장 메뉴에 `🧪 SavePoint 하이드 실험`이 생겨요.
- 지우기: 그 폴더를 지우면 끝이에요. (설정 파일에 남는 실험 기록은 아무 데도 쓰이지 않아요.)
- 휴대폰(Termux)에서 설치하려면 따로 물어봐 주세요.

## 쓰는 법
- 번호를 `2-5, 8`처럼 적고 `빼기` / `되돌리기` / `이 방 전부 해제`.
- 답변을 만들 때마다 패널 아래에 **무엇을 뺐고 무엇을 남겼는지** 기록돼요. `📋 결과 복사`로 통째로 복사할 수 있어요.
- 메시지 번호가 아니라 메시지 자체(보낸 시각·이름)를 기억해서, 앞쪽 메시지를 지워도 같은 메시지를 따라가요.

## 확인할 것 (테스트용 방에서)
준비: 메시지 20개쯤 되는 테스트 방. 일반 `/hide`로 몇 개(예: `/hide 3`), 실험으로 몇 개(예: `4-6, 10`)를 **섞어서** 숨겨요. SavePoint가 숨긴 메시지가 있는 방이면 더 좋아요.

매번 볼 것: 답변 옆 **프롬프트 보기**에서 실험으로 뺀 메시지만 빠졌는지, 다른 메시지가 잘못 빠지거나 남지 않았는지.

| # | 해 볼 것 | 기대 |
|---|---|---|
| 1 | 일반 전송 | 실험 숨김 + `/hide` 둘 다 빠짐, 나머지는 그대로 |
| 2 | 재생성 | 1과 같음 |
| 3 | 스와이프 | 1과 같음(스와이프하는 마지막 답변은 원래 빠짐) |
| 4 | 이어쓰기 | 1과 같음. 이어 쓰는 메시지 자체를 실험 숨김하면 남겨 두고 기록에 "이어쓰기 대상" |
| 5 | 대신 쓰기(impersonate) | 1과 같음 |
| 6 | 그룹 채팅 | 1과 같음 |
| 7 | 앞쪽 메시지 하나 지운 뒤 다시 전송 | 같은 메시지들이 계속 빠짐(번호는 하나씩 당겨짐) |
| 8 | 평소 쓰는 다른 확장 켜고 전송 | 1과 같음 |
| 9 | 실험 숨김 메시지에 표시 확인 | 채팅 파일을 다시 열어도(방 옮겼다 돌아오기) 👻 숨김 표시가 생기지 않음 |
| 10 | Vector Storage의 채팅 검색을 켜고 전송(쓰는 경우만) | 1과 같음. 실험으로 뺀 메시지 원문이 Vector Storage가 넣는 부분에도 없음 |
| 11 | 도구 호출(함수 호출)을 쓰는 방에서 전송(쓰는 경우만) | 1과 같음. 도구 메시지를 골랐으면 기록에 "도구 호출 메시지 — 남김" |

결과 보내 줄 때: `📋 결과 복사` 내용 + 표에서 기대와 다른 칸(무엇을 했는지 한 줄).

## 이미 알고 있는 한계 (실험 범위 밖)
- 프롬프트 관리자에 보이는 토큰 수에는 실험으로 뺀 원문도 들어가요(그 계산은 interceptor를 거치지 않음). 실제 요청에는 빠져요.
- `{{lastMessage}}` 같은 매크로와, 채팅을 직접 읽는 다른 확장에는 뺀 원문이 보여요.
- 이 확장이 꺼져 있거나 설치되지 않은 기기에서는 원문이 그대로 AI에 가요.
- 같은 시각·같은 이름 메시지가 둘 이상이고 구분할 단서가 없으면 빼지 않고 기록에 "구분 못 해 남김"으로 적어요. 고를 때 그런 메시지가 있었으면 글 내용까지 맞아야 빼요(그래서 그 메시지를 고친 뒤에는 남겨요).
- 다른 확장이 고른 메시지와 똑같은 정보의 항목을 요청에 넣어도, 어느 쪽인지 확실하지 않으면 빼지 않아요.
- 도구 호출 메시지는 빼지 않아요(빼면 도구 호출 짝이 깨질 수 있음).
