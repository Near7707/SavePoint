## 특히 봐 줄 곳

**v0.6.95 · 저장 쪽 안내**
1. `unsure` 안내에는 복사 안내를 붙이지 않음. 새 미확인은 쓰기 뒤에만 생기고, 쓰기는 재확인 통과(`setSeen` → `gate.vague` 풀림) 뒤에만 가능하다고 봄. `unsure`와 `gate.vague`가 함께 있는 순서가 있는지.
2. 그 밖에 `gate.vague`가 있는 동안 새로고침·다시 열기를 권하면서 복사 안내가 없는 안내, 또는 메시지 전송·편집을 권하는 막힘 안내가 남았는지.

**v0.6.96 · 기록**

3. `outlineTail`: 요약 AI에 보내는 장면 개요 상한(진행 장면 4,000자, 최근 장면 각 1,500자, 최근 부분부터)이 요약 품질에 충분한지. 저장된 개요·주입은 그대로인지(상한이 요약 AI 입력에만 걸리는지).
4. 입력 한도로 요청 전에 멈출 때 실패 기록의 `입력 내역`(`InputLimitError.parts`, `partsLines`)이 실제 프롬프트 구성과 맞는지, `makePrompt`가 문자열을 돌려주던 기존 경로가 그대로인지.
5. `normalizeResult`의 `id` → `ref`(`new1`은 그대로, `e20`처럼 id 모양이면 `type`·`name`이 있을 때만): 기존 항목을 고치려던 응답이 새 항목으로 잘못 들어가는 경우가 있는지. 같은 응답의 다른 곳이 그 `id`를 가리킬 때 `resolve`가 맞게 잇는지.
6. `applyResult`의 같은 아이템 합치기(`add` + `item`, 같은 `entity`의 지금 쓰는 기록이 있으면 그 기록을 고침): 보관함·사라진 기록 규칙, 되돌리기(리와인드)와 어긋나는 곳이 있는지.

**v0.6.97 · 장면 지침**

7. `SCENES:`와 `SCENE_END_RULE`에 "이야기 속 하루가 지나면 장소·사람이 같아도 새 장면" 문장. 밤샘으로 날짜만 넘어가는 경우 장면이 지나치게 잘게 나뉘는지. `OLD_GUIDE_HASHES`에 v0.6.96 기본 지침 해시(`7lvgk81d3nkee4fh`)를 넣어서, 고치지 않은 지침만 새 기본으로 바뀌고 직접 고친 지침은 그대로인지.

**v0.6.98 · 화면**

8. 버튼 줄을 `flex: 10 1 0`(리와인드 11, 👻 13, 번역 8)으로 바꾸고 v0.6.24 휴대폰 규칙(중지를 글자 폭으로)을 없앰. 스토리 콘솔·레몬 인형뽑기의 버튼 모양 규칙, 420px 이하 여백 규칙과 충돌하는 곳이 있는지. 360px보다 좁은 화면은 검사하지 않음.
