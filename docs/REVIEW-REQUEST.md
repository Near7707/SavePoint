- P2 이전 충돌로 보류한 방을 다시 열면 남은 본체에 연결 → 6번: 이전으로 만든 본체의 사본을 다른 방이 옮긴 기록(이전 완료 표시·`copy-` 단서)이 있으면 보류. 처음 쓰기·다시 열기·재시도가 모두 `copyMoved`

## 특히 봐 줄 곳

1. 3번 줄을 바꾼 결과: 고유값 없는 진짜 예전 방이 예전 사본을 잃으면 항상 보류됨. 이게 정상 경로(예: 실리태번이 나중에 고유값을 채운 예전 방)를 막는지.
2. 6번의 이전 충돌 확인이 `from.kind === 'migrate'`에만 걸리는 것: 분기·새 방 본체에서 놓치는 충돌이 있는지.

4. v0.6.70: 탭 줄이 숨겨졌다 다시 보일 때(휴대폰 빠른 설정), 스킨별 탭 크기에서 44px 비키기.
