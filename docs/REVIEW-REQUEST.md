## 특히 봐 줄 곳
1. `guard` 첫 호출이 모든 경우 첫 요청 직전인지(`landed` 분기의 `guard`는 `sent !== null`만), `putHeldHides` 뒤 `chatTarget`이 비면 바깥 `takeBack`이 되돌리는지.
2. 첫 요청 생략에서 `!landed`를 뺀 것: 새 숨김이 첫 호출 전엔 화면에 없어서 실리태번 저장이 이 변경의 새 숨김을 실을 수 없다는 판단이 맞는지(`home-link.cjs` 41 기대가 "보냄" → "생략"으로 바뀜).
3. 영수증이 없는 방(`mine` 없음)에서 `guard`가 `heldLeft`와 같은 규칙(`!entry.box?.line`)을 쓰는 것.
4. 차례가 실패로 끝나면 건너뛴 계산을 지우는 것, `UNREAD`로 끝난 차례는 다시 계산하지 않는 것(예전 `freeHome`과 같음).
