## 바뀐 것
- 동의한 이동(`이름 변경 이어서 연결`)이 올리는 본체에 `carried: { id(이름 변경 기록 ID), from(출발 이름), wid(이번 업로드 영수증) }`를 함께 저장해요. `memBody`는 안 만들어서 다음 저장에서 빠져요(지우려고 따로 쓰지 않음).
- 다시 열 때 5행 "이미 여기로 옮겨짐" 분기: 기록에 `mem`이 없어도 직접 기록이고 `carriedOn`(표시의 ID·출발 이름이 이 기록 · 표시 `wid` = 본체 지금 `wid` · A 이름표의 기억 · 본체 B·같은 고유값 · 옛 사본 없음 · B 이름표·시작 표시·다른 기억 단서 항목·B 자기 기억 없음)이면 `rename`(`moved`). 본체는 다시 안 쓰고 이름표·단서·A 표시만 써요. `input.left`면 `renamedAway`.
- 그 밖(표시 없음·영수증 다름·다른 기록·B에 다른 연결)은 예전대로 보류, 쓰기 0.
