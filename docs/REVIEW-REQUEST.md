## 고친 것
- `writePlan`: `tag`·`clue` 읽기 실패는 적어 두고 계속 → 이전·본체·옮김·사본 힌트 판정 → 이름표를 못 읽었으면 여기서 `stop: 'read'` → 이름표 판정(`tagChanged` 보류 등) → 단서를 못 읽었으면 `stop: 'read'`. 그래서 다시 읽은 이름표가 다른 연결이면 단서 실패가 겹쳐도 보류(`placed` 없음, 화면 기억 없음).
- 그대로: `mem`·`start`·`moved`·`hint` 읽기 실패는 곧바로 `readFail`.
