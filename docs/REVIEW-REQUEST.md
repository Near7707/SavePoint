## 특히 봐 줄 곳
1. `ready`는 이 화면이 아는 조건만 봐요(권한·답변 중·미확정·원문 지문·화면 숨김/🔖가 2단계 읽기와 같음). 다른 탭이 그사이 채팅 파일을 바꾼 건 기억을 쓴 뒤 마지막 읽기에서 잡아요(42a·42b, 성공 없이 멈춤).
2. UNREAD 때 화면 기억은 새 것으로 바꾸고 H2는 그대로 두되, 안내만 `checkMem`으로 바꿨어요. H2를 지우면 저장 타이머와 되감기 예약을 막는 장치가 풀려서예요. 이 판단이 맞는지 봐 주세요.
3. PENDING 때는 화면 기억을 옛 것 그대로 둬요. 다시 열 때까지 멈추니까요.
4. 겹 장치라 망가뜨리기로 안 잡힌 곳:
