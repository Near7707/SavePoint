## 바뀐 것
- **P1:** 서버에서 그 메시지의 🔖가 꺼진 걸 확인하면 화면의 🔖와 스와이프 흔적도 지워요(`keepOff`, 파일은 안 씀). 차례 첫 읽기에서 보면 곧바로 지워요. 요청 직전·다시 보내기 전 `guard`에서 보면 되돌림(`keepBack`)을 먼저 하고, 해제 반영은 `finally`에서 마지막에 해요.
- **P2-a:** 재개 번호 `keepEra`를 둬요. 요청은 만들 때의 번호와 같을 때만 유효해요. 번호는 실제로 멈췄던 방이 다시 저장 가능해지는 곳에서 올려요(`roomOpened`·`fitEnd`·`fitChecked`·확인 대기 해소·차단 뒤 `verifyRoom` 통과·`recheckHome('auto')`의 H2 지우기). 답변 때문에 기다린 경우(`busy`)는 번호를 그대로 둬요.
- **P2-b:** `putHeldHides`도 `keepWait`이면 건너뛰어요.

## 특히 봐 줄 곳
1. 재개 지점 목록이 빠짐없는지. `roomOpened`는 `new` → `linked`로만 바뀌어도 불려서 그때도 요청을 버려요(안전한 쪽).
2. `busy` → `verifyRoom` 통과는 번호를 안 올려요. 다른 차단(`bad`·`unread`·`unknown`)에서 통과할 때만 올려요.
3. 첫 읽기의 "다른 곳에서 끔" 판단(서버의 같은 위치 메시지에 🔖 근거 없음)으로 이제 화면 🔖도 지워요. 잘못 판단하면 화면 🔖가 사라져요.
4. 검사는 `다시 확인` 재개(`roomOpened`)만 있어요. `fitEnd`·`fitChecked`·확인 대기 해소·`verifyRoom` 재개 길은 검사가 없어요.
