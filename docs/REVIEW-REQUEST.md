## 바뀐 것
- 재개(`d.carried`)는 채팅 목록을 확인한 뒤, 첫 연결 파일을 쓰기 전에 본체와 연결 파일을 다시 읽어요(`carryResume`).
  - 본체에 이번 기록·출발 이름·지금 영수증의 이동 표시가 있고, A 이름표가 이 기억으로 linked, B 이름표·시작 표시·다른 기억 단서·B 자기 기억이 없으면 → 이어서 써요.
  - A 이름표가 이 기억으로 `renamed → B`, B 이름표가 이 기억·고유값으로 linked, 본체가 B·같은 고유값이면 → 쓰기 0으로 그 최신 본체를 화면에 붙여요(영수증이 바뀌었거나 표시가 빠졌어도 됨).
  - 그 밖(표시가 빠지고 B 이름표 없음, 본체가 A로 돌아옴, B에 다른 기억 단서 등) → 쓰기 0, `carryResumeChanged` 보류. 판정 때 읽은 표시는 안 써요.
  - 읽기 실패 → `readFail`.
