## 특히 봐 줄 곳
1. `splitKeeps`로 첫 답의 기록을 잃는 길이 남았는지, 반대로 너무 엄해서 쓸 만한 재응답을 자주 버리지 않는지(`advance` → `explicit`로 바꿔 적기, 시계 덧붙이기, `add` → `update` 등은 빠진 것으로 봄 → 첫 답 저장).
2. 변경 짝짓기: 같은 모양 + (같은 글 또는 같은 메시지 묶음), 하나씩 짝지음. 같은 메시지에서 다른 내용으로 바뀐 변경(모양까지 같음)은 통과하는데, 이 정도면 충분한지.
3. 새 장면에서 기준을 비우는 것으로 a2 P3(한 장면이 새벽을 넘겨 아침까지)가 그대로 잡히는지, 놓치는 경우가 생기지 않는지.
4. `tries`·`자동 보정` 문구가 실제 처리와 맞는지.
