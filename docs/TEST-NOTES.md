## 돌리기
- Node: `node --test tests/*.test.mjs` (c5 기준 515 통과 / 0 실패 / 3 건너뜀, 건너뜀은 #0 이어하기).
- 브라우저: `export NODE_PATH=/opt/node22/lib/node_modules:/home/claude/.npm-global/lib/node_modules` 뒤 `node tests/browser/<이름>.cjs`. c5 기준 63묶음, 한꺼번에 약 40분~1시간(CPU 2개라 다른 검사와 같이 돌리면 더 걸림). 한꺼번에 돌릴 때 `inject-wait`·`keys`(예전엔 `status`도)가 타이밍으로 가끔 실패 → 따로 다시 돌려 확인. 끝나면 종료 코드와 `grep -l "PAGE ERROR"`(검사 모드 오류 0이어야 함).
- 전체 실행 스크립트 예(`/tmp/fullrun.sh`, **복사본 폴더 밖에 두기** — 복사본을 `rm -rf`로 새로 만들 때 스크립트까지 지워져 30분을 날린 적 있음): 레포를 `/tmp/full`에 `tar --exclude=.git`으로 복사 → `cd /tmp/full; mkdir -p res; : > res/_summary; for f in tests/browser/*.cjs; do n=$(basename $f .cjs); timeout 600 node $f > res/$n.txt 2>&1; echo "$n $?" >> res/_summary; done; echo DONE >> res/_summary`를 `nohup …&`로.
- 기다리기: `sleep`을 길게 한 명령은 도구 기본 timeout(2분)에 걸림 → `for i in $(seq 1 58); do grep -q DONE res/_summary && break; sleep 10; done`(도구 timeout 600000)를 여러 번. 끝나면 `awk '$2!=0{print $1}' res/_summary`.
- 몇 묶음만 동시에: `for f in "$@"; do ( timeout 600 node tests/browser/$f.cjs > /tmp/r1/$f.txt 2>&1; echo "$f $?" >> /tmp/r1/_summary ) & done; wait`. 오래 걸리는 묶음(`b2b-race` 3분 이상, `home-link` 약 6분)은 백그라운드로.
- 새 코드·예전 코드 동시 실행: 두 줄을 `( … ; echo DONE >> 파일) &` 후 `wait`.
