# v0.7.0 실제 실리태번 확인 목록

`main`에 합치기 전에 실제 실리태번에서 확인해요. **"꼭 볼 것"을 통과하지 못한 경로는 출시 전에 따로 해결해요**(합격 기준 8). 자동 검사(`tests/browser/send-guard.cjs`)는 모의 환경이라 실리태번 실제 동작은 여기서만 확인돼요.

## 준비
- 시작 전에 💾 백업(세이브 슬롯 또는 채팅 내보내기).
- 테스트용 방 두 개:
  - **정상 방**: SavePoint로 기록한 1:1 방(숨김이 기억에 덮인 방).
  - **빠지는 방**: 숨김이 기억에 덮이지 않는 1:1 방. 만들기 쉬운 방법은 SavePoint 숨김이 있는 채팅을 복사(가져오기)해서 기억 없이 여는 것이에요(창에 "보류" 안내가 떠요). 1차 확인(2026-11-19)에서 실제로 이렇게 만들었어요.
- **그룹 확인용**(복제본 없이): 시험용 그룹(캐릭터 두 명 이상)에서 평소대로 대화하고 세이브해 기록·숨김을 만들어요. PC에서 F12 → Console에 아래 한 줄(붙여 넣기가 막히면 먼저 `allow pasting`)을 넣으면 새로고침 전까지 기억 파일 **읽기만** 실패해요(저장은 그대로). 다른 방에 갔다가 그룹 방을 다시 열면 기억을 못 읽은 방(창에 "다시 확인" 안내)이 되어 브리핑이 없으니 숨긴 원문이 빠지는 방이 돼요. 끝나면 F5. 개발자도구 Network의 요청 차단은 기억 파일 주소 끝 `?t=…`가 매번 달라서 안 먹혀요(2차 확인 때 알게 됨).
  ```
  const f0 = window.fetch; window.fetch = (u, o) => (String(u).includes('/user/files/savepoint-mem-') && !(o && o.method && o.method !== 'GET')) ? Promise.reject(new Error('test block')) : f0(u, o);
  ```
  확인 순서: 보내기·취소 → 이번만 → **재생성은 마지막에**(그룹에서 재생성·삭제를 하면 새로고침 전까지 확인창 대신 알림만 떠요).
- 실리태번 설정에서 **빈 전송 문구(`send_if_empty`)를 켜 두기**(4번 확인용).

## 꼭 볼 것 (합격 기준 8)
1. **정상 방은 묻지 않음** — 정상 방에서 평소처럼 보내기 → 확인창 없이 답변.
2. **취소** — 빠지는 방에서 보내기 → 확인창 → `취소` → 답변 안 만들어짐, 보낸 글은 채팅에 한 번만 남음, 보내기 버튼이 돌아옴, 취소 알림이 뜸.
3. **창 닫기 = 취소** — 확인창을 버튼 없이 닫을 수 있으면(Esc 등, 휴대폰에서 방법이 없으면 PC에서) 닫기 → 2와 같음(답변 안 만들어짐). 자동 검사(`send-guard` 3)는 확인됨. **1차: PC에서 Esc ✅.**
4. **`답변 만들기`** — 2 뒤 취소 알림을 누름 → SavePoint 창이 열리고 맨 위에 `답변 만들기` → 누름 → 확인창이 다시 뜸 → `이번만 그대로 답변 만들기` → 답변이 만들어짐. **새 사용자 글이나 빈 전송 문구가 추가되지 않음**(빈 전송 문구를 켠 채로).
5. **이번만은 한 번** — 4 뒤 다시 보내기 → 또 물음.
6. **확인창 중 방 옮기기** — 확인창을 띄운 채 다른 방으로 → 그 답변은 안 만들어짐. 남은 창을 닫아도 새 방에 아무 일 없음. **1차: 손으로는 못 함**(확인창이 화면을 막아 방을 옮길 수 없음 = 사람이 겪을 일 없음). 자동 검사(`send-guard` 6·7·8·25)로 갈음.
7. **재생성·스와이프·이어쓰기는 묻지 않음** — 빠지는 방에서 각각 → 확인창 없이 그대로 동작, 기존 답변이 사라지지 않음.
8. **그룹** — 빠지는 그룹 방에서 보내기 → 한 번만 물음. `취소` → 다음 캐릭터가 이어서 답하지 않음. `이번만` → 그 묶음의 캐릭터들이 모두 답함. 그룹 재생성은 묻지 않고 기존 답변이 새 답변으로 바뀜(사라지지 않음).

## c4에서 볼 것 (`이 방에 기억 복사해 복구`, Esc)
- 기억이 연결된 방을 지운 뒤 그 복제본을 열면 보류 안내에 `이 방에 기억 복사해 복구` 버튼이 보이는지(기억이 기록한 원문이 그 복제본과 모두 같을 때만).
- 확인창에 다른 방 이름·지금 방 이름·기록 범위가 알아보기 쉬운지. `취소`면 아무것도 안 바뀌는지.
- 확인하면 "기억 사본을 만들어 연결했어요" → 그 방에서 세이브·체크포인트가 평소대로 되는지. 다른 복제본은 계속 보류(후보가 둘이 됨)인지.
- 복구한 방에 기억이 덮지 못하는 숨김이 있으면 "숨김 정리가 필요해요" 안내 + `원문과 기억 맞추기`로 이어지는지.
- `답변 만들기` 준비 창이 떠 있는 동안 Esc → 빨간 실패 대신 "답변을 멈췄어요" 안내(PC).

## 여유 있으면 볼 것
- 확인창 버튼 이름(`취소`·`이번만 그대로 답변 만들기`)이 제대로 보이는지, 확인창 끝 "취소한 뒤 SavePoint 창에서 원인을 확인하고…" 문장이 줄을 바꿔 보이는지.
- `답변 만들기` 안내에 "다시 시도할 때도 상태를 확인해요…"가 보이는지.
- `답변 만들기`를 누른 뒤 준비 창이 답변이 끝날 때까지 남고 끝나면 저절로 닫히는지. 창 안 `중지 요청`을 누르면 문구가 바뀌고 답변이 멈추는지(스트리밍 중이면 나온 부분이 남음). 준비 중에 눌러 안 멈췄으면 다시 눌러 멈추는지.
- `답변 만들기` 거절: 입력칸에 글(띄어쓰기만도)이나 보내지 않은 첨부가 있으면 거절 안내.
- 글을 고치거나 방을 옮기면 `답변 만들기` 버튼이 사라지는지.
- 방을 열자마자 보냈을 때 잠깐 기다렸다 진행(또는 물음)하는지.
- 취소 뒤 자동 기록·🔖 복구가 평소처럼 도는지('답변 중'으로 남지 않음).
- 서버가 느릴 때 준비 창 안내가 10초 뒤 바뀌는지.
- 그룹: 메시지를 지운(또는 재생성한) 뒤에는 새로고침 전까지 확인창 대신 알림만 뜨고 답변은 그대로 만들어지는지, 새로고침하면 다시 확인창이 뜨는지, 1:1은 그대로 묻는지. 재생성을 누르고 바로 1:1로 옮겨도 알림만 뜨는지.
- 슬래시 명령(예: `/echo 안녕`)을 보낸 뒤 그룹 재생성이 묻지 않는지.
- 답변이 다시 확인창에 걸리면 그 확인창이 준비 창 위에서 눌리는지(두 창이 겹칠 때).

## PC가 있을 때만 (키보드, 출시를 막지 않음)
- 준비 창을 Esc(두 번 + 확인 포함)로 닫을 수 없는지.
- 준비 창이 열릴 때 포커스가 버튼이 아니라 안내 글에 있는지(이어서 친 띄어쓰기·Enter로 중지가 안 되는지).
- Tab으로 `중지 요청`을 고르고 Enter·Space로 중지되는지.
- 입력칸에 포커스를 둔 채 `답변 만들기`를 누르고 계속 쳐도 글이 지워지지 않는지.

## 합치기 전에 함께 볼 저장 쪽 (b)
- 평소처럼 체크포인트·퀵세이브·하이드·원문 고치기가 되는지.
- 기존 방 이전·새 방·갈래·채팅 삭제·가져온 사본에서 기억이 섞이지 않는지.
- 이름 변경(특수문자 포함): 열어 둔 방은 기억이 따라감, 채팅 목록에서 바꾼 다른 방은 보류. 목록에서 한 번 바꾼 1:1 방은 `이름 변경 이어서 연결` 버튼이 보이고, 확인하면 이어지고 취소하면 그대로. 그룹·두 번 바꾼 방은 버튼 없음.
- 방을 열기만 해서는 채팅 파일이 저장되지 않고, 새 숨김은 다음 세이브·체크포인트·👻 때 걸리는지. 예전 형식 기억 방도 바로 세이브가 평소처럼 되는지.
- 숨김으로 멈춘 방에서 `원문과 기억 맞추기`가 그 숨김만 풀고 이어지는지, 원문이 바뀐 방에서는 확인창(되감기·검토)이 알아보기 쉽고 취소하면 아무것도 바뀌지 않는지.
- 🔖 메시지를 스와이프하거나 새 답변을 받으면 잠깐 뒤 🔖가 다시 붙고, 그사이 원문이 숨겨지지 않는지.
